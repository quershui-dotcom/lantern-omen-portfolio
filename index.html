02 / WORLD

不是打败怪物，
而是穿过恐惧。

首页将原本孤立的菜单界面扩展为一段可读的开场：先让玩家理解“灯”是什么，再理解自己为什么必须向前。

WORLD PREMISE / 雨夜祠堂

灯是唯一的边界

暖橙代表可见、可控与短暂的庇护；青绿则指向游离的魂火与未知。两种色温持续冲突，让每一次离开灯下都成为有代价的决定。

情绪弧线孤立 → 发现 → 压迫 → 反抗
叙事锚点灯、雨、符纸、祠堂、旧铃
视觉语法暗场留白、局部暖光、像素颗粒

04 / LOOP

让叙事落在
每一次操作上。

页面结构遵循“开场钩子 → 世界规则 → 核心循环 → 设计系统 → 试玩收束”，在不进入游戏前就完成一次完整的情绪递进。

看见

用灯火与 HUD 层级提示安全区、威胁与当前目标，避免玩家在首屏迷失。

选择

用升级三选一制造短暂停顿；美术、名称与成长方向共同服务于世界观，而非只是属性加成。

承受

用敌人密度、视野压力与色彩入侵放大风险，最后让阶段性敌人完成体验的情绪封口。

05 / SYSTEM

暗色，不等于
看不清。

本次调整将已有游戏的暖橙与魂火青绿提炼为网站设计令牌，并以低密度、长呼吸的留白让叙事和试玩入口都清晰可达。

Color / 暗色令牌

夜幕底色#090A11
灯火强调#F09A45
魂火信息#66D9C0
纸张正文#E9E2D4

Type / 字体层级

标题使用衬线中文，像一页被雨水浸过的旧志。

信息使用等宽字，保持原型、系统与档案的精确感。

Motion / 动效原则

  • 灯笼只做缓慢浮动，不抢正文。
  • 区块按阅读节奏淡入，不滚动劫持。
  • 为减少动态偏好提供静态终态。
