## 项目定位

- 类型：中国民俗怪谈 Roguelite
- 方向：系统策划 / 产品运营向作品集
- 目标：用可公开访问的网页作品集，展示从世界观到系统健康度的完整设计思考与交付能力
- 核心情绪：被窥视、被操控、未知靠近——恐怖感来自空间、操控与窥视，而非血腥或跳脸

---

## 世界观与视觉母题

来自作品集首页视觉迭代（详见 [Notion 展示页](#快速链接)），《灯谶》的首屏叙事画面围绕三个母题展开：

| 层级 | 画面元素 | 叙事职责 |
| --- | --- | --- |
| 远景 | 雨雾、昏黄月亮、祠堂屋檐、枯树、垂落符纸 | 建立雨夜祭场与民俗禁忌感 |
| 中景 | 半透明皮影人偶、微弱青绿色眼睛、操纵杆 | 呈现“被窥视、被操控”的未知威胁 |
| 前景 | 破旧河灯、摇曳烛火、破碎水面倒影 | 将灯火从装饰变成可被夺走的安全边界 |

视线沿 月亮 → 皮影 → 河灯倒影 形成右上至右下的斜向引导，在不侵占左侧信息区的前提下，把“灯火”这一安全边界与“皮影操控”关系绑定，直接表达游戏气质。

## 作品集内容框架

作品集围绕以下系统维度展开，具体设计与数据详见作品集页面：

- 核心循环：Roguelite 的单局 / 长线循环结构，以及玩法与叙事的耦合方式
- 叙事互动：玩家与世界观、NPC、机制的互动路径，以及“被未知操控”情绪的可玩化
- 版本内容：已交付与规划中的版本节奏、内容模块与优先级
- 系统健康指标：用于衡量循环与留存的关键指标定义与监控方式
- 可公开试玩：试玩入口、交付质量与体验验证

## 视觉规范与交付

- 底色：深黑蓝灰，低饱和、电影感暗色民俗档案美学（避免赛博霓虹）
- 灯火橙 #E87C30：只用于河灯与关键视觉焦点
- 幽魂青绿 #1D9E75：只作为异象与危险提示
- 约束：恐怖感来自空间、操控与窥视，不使用游戏内实机截图、HUD、角色立绘或文字首屏
