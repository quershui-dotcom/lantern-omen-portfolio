# 《灯谶》审美母题：铜金法器 + 符纸 + 双色魂火

> AI 美术视觉规范基础

---

## 视觉关键词体系

以**黑底 / 雨夜冷场**为底，使用以下元素建立强识别视觉语言：

| 关键词 | 类别 | 应用说明 |
| --- | --- | --- |
| 旧铜 | 材质 | 法器、器物的基础质感 |
| 纸符 | 元素 | 悬挂符纸、书写文字载体 |
| 红绳 | 元素 | 连接、绑定、封印的视觉符号 |
| 铃 | 器物 | 铜铃、警示与仪式道具 |
| 提灯 | 核心道具 | 玩家手持的核心视觉焦点 |
| 青魂 | 特效色 | 异象、危险提示、徊灵系 |
| 湿石 | 环境 | 雨夜地面的材质表达 |
| 雨夜 | 氛围 | 整体环境基调 |

## 双色魂火特效规范

| 颜色 | 名称 | 色值 | 用途 |
| --- | --- | --- | --- |
| 暖橙 | 灯火 | #E87C30 | 玩家输出、灯焰与照夜；只用于河灯与关键视觉焦点 |
| 青绿 | 幽魂 | #1D9E75 | 回复、残魂、徊灵与奖励路径；只作为异象与危险提示 |

## 转化为需求

1. 建立《灯谶》视觉关键词：旧铜、纸符、红绳、铃、提灯、青魂、湿石、雨夜
2. 原型中保留**橙火 / 青魂**两个高辨识特效色
3. 作品集页面中用此母题统一 P01、P04、P05、P08 的视觉语言

## 不可照搬点

不可直接复刻单张概念图的角色造型、构图和具体器物组合；需要抽象成**材质、颜色、轮廓、特效规则**。
