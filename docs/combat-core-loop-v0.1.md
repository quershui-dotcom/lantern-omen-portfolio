# 战斗约定与核心循环升级｜v0.1

> 状态：已确认，进入原型实现（2026-08-14）

---

## 一句话设计哲学

提灯行者在雨夜祭场中，以走位聚怪、点亮祭灯、积蓄灯焰，并在濒临失控时照破邪祟。

---

## 已确认的核心四动词

| 动词 | 输入 | 设计职责 |
| --- | --- | --- |
| **基础瞬影** | Space | 开局拥有的短位移与关键规避；后续由斩命流强化为双充能、反击或冷却优化 |
| **灯焰** | 被动积累 | 击杀、完美闪避、点亮祭灯与事件成功共同积累的唯一主动战斗资源 |
| **照夜** | Q | 满灯焰时释放的破围/破机制爆发：范围伤害、击退普通怪、清除普通弹体，并对精英与 Boss 施加显形积累 |
| **祭灯** | E | 需要进入范围并持续引导的地图目标；以风险—回报驱动路线与爆发时机选择 |

---

## 局内核心循环

```
聚怪与走位 → 击杀、完美闪避、点灯 → 积累灯焰 → 选择照夜救场或保留 → 升级构筑改写下一轮循环 → (回到起点)
```

---

## 构筑约定

- 第 4 次升级后，选择次数最多的流派确定为**主脉**；若并列，由玩家选择。
- 允许保留 1 个辅脉，避免四流派全拿形成无差别最优解。
- 主脉后续选项权重提高 25%，并在第 6 次与第 10 次升级提供核心节点。
- 四流派职责：**灯火** = 持续清场；**徊灵** = 续航守灯；**斩命** = 完美闪避反打；**回响** = 组织战场与连锁。

---

## 终局结构

| 时间 | 事件 |
| --- | --- |
| 0—540 秒 | 六阶段波浪上升，逐步引入追猎、冲锋、远程、仪式与混编压力 |
| 540 秒 | 停止常规波次，生成唯一终局 Boss"灯笼巨影"与少量专属随从 |
| 600 秒前击败 Boss | 获得"谶验达成"胜利 |
| 600 秒 Boss 未击败 | 进入 20 秒"灯灭倒计时"；倒计时内击败为险胜，否则失败 |

## 设计边界

- 单人局内构筑型 2D 俯视角 Roguelite；不引入组队、切人或抽卡命座。
- 显性战斗资源仅保留 HP、XP、灯焰，避免多资源堆叠。
- 所有高危预警采用颜色 + 形状 + 音效的三重表达。
