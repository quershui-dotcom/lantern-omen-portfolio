# 《灯谶》战斗数值总表

> 展示《灯谶》的战斗基础数值框架，以及这些参数如何共同服务单局体验

---

## 体验目标

- 前 30-60 秒建立"能打、能躲、能成长"的基础手感
- 普攻需要提供稳定的击杀反馈，避免前期拖沓
- 生存不能只依赖血量，而应由移速、成长和清场能力共同决定
- 中后期压力主要来自节奏与决策，而不只是怪物数值膨胀

---

## 玩家基础参数

| 参数 | 当前值 | 作用理解 |
| --- | --- | --- |
| HP | 110 | 保证前期容错，避免首局过早暴毙 |
| Damage | 18 | 保证基础击杀效率 |
| Fire Rate | 0.36 | 控制普攻输出频率与手感 |
| Crit | 0.08 | 提供波动反馈与成长空间 |
| Projectile Speed | 24 | 影响命中感与清怪效率 |
| Move Speed | 10.5 | 决定走位空间与操作压力 |
| Magnet | 6.5 | 影响资源回收效率与成长流畅度 |
| Armor | 0 | 作为后续成长向生存变量 |

---

## 强度拆分方式

我把玩家强度拆成四个维度来理解，而不是只看单项伤害：

| 维度 | 包含指标 | 问题定位 |
| --- | --- | --- |
| 输出效率 | Damage / Fire Rate / Crit | "打不动" |
| 生存容错 | HP / Armor / Move Speed | "活不下来" |
| 清场能力 | 范围伤害 / 自动索敌 / 主动技能 | 清场效率不足 |
| 成长效率 | 经验获取 / 拾取效率 / 升级频率 | "成长太慢"或"流派收益不明显" |

## 敌人参数模板

| 模块 | 当前配置 | 设计作用 |
| --- | --- | --- |
| 普通怪血量 | 32 → 126（随阶段提升） | 作为基础时间压力来源 |
| 敌人速度 | 4.7 → 6.35（随阶段提升） | 迫使玩家移动与站位 |
| 精英占比 | 5% → 30% | 形成局部峰值与压迫感 |
| 怪群规模 | 2 → 7 | 控制场面密度与清场需求 |

---

## 数值模型理解

在《灯谶》的战斗设计里，我不把"难度"简单理解为怪物更肉，而是通过三个变量共同控制：

- **时间维度**：刷怪频率是否更紧
- **空间维度**：怪群规模是否挤压走位
- **强度维度**：敌人血量、速度、精英占比是否同步抬升

目标是让玩家感受到的是**"压力结构变化"**，而不是单纯的数值放大。

---

## 当前结论

当前基础参数已经能够支撑首局体验成立。后续重点不是继续堆参数，而是验证这些参数在不同成长分支下是否会导致明显失衡。
