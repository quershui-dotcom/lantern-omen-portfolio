## 核心体验三要素

| 要素 | 描述 | 作品集映射 |
| --- | --- | --- |
| **提灯行者** | 玩家身份——手持灯火在黑暗中前行的角色 | P04 Worldview：雨夜祭场与灯谶主题 |
| **雨夜祭场** | 场景空间——被黑雨笼罩的祠堂祭场，有固定路线锚点 | P05 Gameplay：提灯、清场、限时任务、Boss 压力递进 |
| **清场生存** | 循环机制——在怪潮中清场、成长、抵达祭灯并做出选择 | 核心循环：聚怪 → 击杀/点灯 → 积累灯焰 → 照夜/保留 |

## 可借鉴点（来自灵感记录）

当前原型已形成提灯行者身份、雨夜祭场场景、敌群压迫与清场生存循环，可作为作品集 P04/P05 的体验主轴。

## 不可照搬点

不要只展示氛围图，需要用任务、战斗节奏和玩家反馈证明它是可玩的系统，而不是静态概念。
