# 《灯谶》Product Ops Workspace

> 原创虚拟游戏产品运营案例工作区

**项目身份**

《灯谶》是一套以中式志怪 Roguelite 为载体的系统策划与产品运营案例：从战斗原型、互动叙事、版本内容到验证口径，呈现一条可持续迭代的产品证据链。

### 四流派系统接口

| 流派 | 核心方向 | 体验目标 |
| --- | --- | --- |
| 灯火 | 直接伤害 / 点燃 / 射击强化 | 稳定持续输出，建立最直接的正反馈 |
| 徊灵 | 自动索敌 / 回复 / 容错 | 降低操作负担，提升续航与稳定性 |
| 斩命 | 暴击 / 机动 / 爆发 | 高风险高回报，强调贴边输出与操作感 |
| 回响 | 范围清场 / 节奏爆发 | 中后期形成明显场面处理能力 |

> 四流派不仅是战斗分工，也是内容与运营的可配置接口：灯火承接稳定输出事件，徊灵承接陪伴与续航内容，斩命承接高风险挑战，回响承接群体目标与仪式异象。

## 当前产品版本结论

目前，《灯谶》已从题材原型推进为可公开试玩的系统运营案例：完成祭灯节点、遗影证词、遗愿状态、命簿结局、战斗技能反馈与外网发布；后续将围绕祭灯发现、遗愿分布、结局到达与重开意愿开展真实测试与内容迭代。

### 当前迭代重点

1. 验证前 2 分钟成长反馈是否足够明显。
2. 验证 180s-300s 是否出现中期压力断层。
3. 验证灯火流是否过于稳定，导致其他流派吸引力不足。
4. 验证生存向选择是否缺少即时收益感。
